# Personal-use notice

This project is a personal-use prototype built for the Ontario All-Quote Agent Challenge. It is
not a commercial product and must not be treated as one.

- It obtains and compares auto insurance quotes for **one person only: me**, using my own accurate
  information.
- It does not obtain quotes, make calls, or submit information for anyone else — no friends,
  family, customers, or the public.
- It does not sell insurance, bind coverage, provide licensed advice, or decide which coverage is
  suitable. It stops and hands off to a licensed professional if the flow reaches that point.
- It does not purchase, bind, renew, cancel, or modify any policy, and never submits payment
  information or an electronic signature.
- It is not deployed, sold, licensed, marketed, or published as a service, and must not be treated
  as production-ready telephony/consent compliance if a voice channel is ever added.
